# Royal Water Tank Cleaning Services - Website

Sab files ek hi jagah (root) me hain, koi folder nahi.

## Blog me nayi post
1. Nayi file banayen: Add file -> Create new file, naam `post-meri-post.md` (small letters aur `-`).
2. Post likhen (`## Heading`, `- list`, `**bold**`).
3. `posts.json` kholen, pencil icon dabayen aur list me nayi entry add karen:
   {"slug":"meri-post","title":"Post ka title","date":"2026-11-05","excerpt":"Ek line ka khulasa","image":"underground-tank.jpg"},
   (slug wohi jo file ke naam me `post-` ke baad hai.)
4. Commit karen.
