# Royal Water Tank Cleaning Services - Website

## Blog me nayi post kaise lagayen
1. GitHub me `blog/posts/` folder kholen -> Add file -> Create new file.
2. File ka naam likhen, jaise `my-new-post.md` (sirf small letters, numbers aur `-`).
3. Neeche post likhen (`## Heading`, `- list`, `**bold**`, `![photo](../../assets/images/photo.jpg)`).
4. `blog/posts.json` kholen, pencil icon dabayen, list ke upar nayi entry add karen:
   {"slug":"my-new-post","title":"Post ka title","date":"2026-11-05","excerpt":"Ek line ka khulasa","image":"assets/images/photo.jpg"},
5. Commit karen. 1-2 minute me post website par aa jayegi.

## Nayi photo gallery me
`assets/images/` me upload karen, phir `assets/gallery.json` me ek line add karen.
